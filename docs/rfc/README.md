# Requests for Comment

Use an RFC for a proposed change to public contracts, core domain semantics, a security boundary, the extension model, the agent-authority model, policy-pack structure, compatibility promises, repository strategy, or primary language strategy.

Start with a Discussion or issue, then copy `0000-template.md` using the next four-digit number. A maintainer records the final status. An accepted RFC defines direction; implementation still requires bounded issues and applicable ADRs.
