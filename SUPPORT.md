# Support

NZ Ledger is in a founding and design phase. No production software exists and no guaranteed support is offered.

- Use GitHub Discussions for questions, design exploration, and community help.
- Use issues for reproducible defects and accepted, bounded work.
- Use GitHub private vulnerability reporting for security concerns.

Do not post confidential financial information, personal data, credentials, recovery material, or secrets. There is no private commercial support channel and no promise of accounting, tax, legal, regulatory, or production advice.
